# 十一种风格基因

> 根据主体、内容类型和选题调配以下基因，每类内容的常用搭配写在 `types/` 对应文件开头。**基因只是辅料库，按需取用，不设数量和占比配额**；不让任何单一基因主导输出风格。示例中的数字均为示意，真实写作必须有来源。

## 1. 商业洞察
- **特征**：把产品动作翻译为商业价值，用老板、投资人、采购方能听懂的语言讲
- **手法**：先讲“这件事为什么重要”，再讲“具体做了什么”；用行业对比和格局定位
- **适用**：深度文章、品牌稿、产品软文、新闻通稿（B2B、软件、AI、专业服务尤其常用）
- **示意**：不是“我们上线了智能排班”，而是“当人力成本成为连锁门店最大的固定支出，排班这件小事开始直接影响利润”

## 2. 观点锐度
- **特征**：敢下判断，敢说“这件事很多人理解错了”
- **手法**：反常识切入打破预期；观点明确不骑墙；锐度对事不对人，不点名贬低同行
- **适用**：深度文章、知识科普、公众号传播型内容
- **示意**：不是“选择适合的设备很重要”，而是“多数工厂换设备亏钱，不是买错了型号，是没算停线那三天”

## 3. 专业纵深
- **特征**：对原理、工艺、标准不含糊，引用有据
- **手法**：关键点给出原理级解释；数据和指标有出处；不说“性能大幅提升”这种空话
- **适用**：专业解读、实操教程、产品手册与服务说明、面向懂行受众的内容
- **示意**：不是“面料更透气”，而是“经纱换成了空心纤维，同样克重下透气量提升了一档（以检测报告为准）”

## 4. 通俗趣味
- **特征**：把硬核内容用生活化比喻讲明白，让外行也愿意转发
- **手法**：类比、场景还原、把专业语言翻译成人话；比喻要准确，不为好玩失准
- **适用**：知识科普、公众号传播、短视频脚本、种草笔记
- **示意**：不是“采用分区控温技术”，而是“冰箱里像住了三户人家，各开各的空调，谁也不串味”

## 5. 产业落地
- **特征**：关注从方案到现场的最后一公里，重视落地细节和行业 know-how
- **手法**：写案例不只写“效果好”，写怎么部署、踩了什么坑、为什么这么选
- **适用**：案例故事、实操教程、专业解读、产品软文
- **示意**：不是“帮助客户降本增效”，而是“上线头两周，仓库主管每天还是手抄一遍单子对照，直到第三周才敢把纸质单撤掉”

## 6. 实战复现
- **特征**：以“别人看完能照着做”为最高标准，步骤可复现、效果可验证
- **手法**：问题 → 选型 → 步骤 → 踩坑 → 效果对比 → 总结
- **适用**：实操教程、专业解读（发在专业社区时）、产品手册
- **示意**：不是“设置非常简单”，而是“按这五步走，十分钟能跑通；第三步的权限没开，后面全白做”

## 7. 多信源与数据锚定
- **特征**：多信源交叉验证拼完整地图；论点用精确数据和对比锚定；冷静客观
- **手法**：多信源拼图（报告、标准、公开数据、一线访谈）+ 极限对比 + 概念具象化 + 层层递进（现象 → 原因 → 影响）
- **适用**：深度文章、专业解读、品牌稿（需要行业纵深时）
- **示意**：不是“行业增长很快”，而是把两组可查证的公开数据并排放，让读者自己看出差距

## 8. 论证推进
- **特征**：递进论证（现象 → 原因 → 深层逻辑 → 价值判断 → 建设性方向）；角度淬炼；短句锤判断、长句铺论证
- **手法**：先给判断再给证据；替受众说出心里话；正面开头三范式；素材交替（见 `argumentation-guide.md`）
- **适用**：深度文章、品牌稿（需要“有态度但不流量化”时）、声明与回应（需要把道理讲透时）
- **边界**：宣发内容里信息增量优先于观点表达；产品植入场景不做激烈破立；共情对象是受众的真实处境，不是社会情绪

## 9. 体验种草
- **特征**：像一个真用过的人在分享，细节具体、利弊都说
- **手法**：使用场景 → 具体感受（看得见、摸得着的细节）→ 适合谁不适合谁 → 实用提示；不吹满分
- **适用**：种草笔记、产品软文、短视频脚本、上新文案
- **边界**：第一人称体验只写真实发生的（用户提供的体验素材或可授权的顾客反馈）；商业合作按平台要求标明

## 10. 人情烟火
- **特征**：有街坊味、有人的温度，写老板、师傅、顾客之间的真实关系
- **手法**：一个具体的人 + 一个反复出现的小动作或物件 + 一句本地人才懂的话
- **适用**：门店与本地生活、工作室与小微品牌的品牌稿、开业稿、案例故事、短视频脚本
- **示意**：不是“我们坚持匠心”，而是“老板每天早上五点去菜场，摊主看见他就把留好的筒骨提出来”（细节须来自真实素材）

## 11. 品牌叙事
- **特征**：把主体的来路、选择和坚持讲成一条可信的线，不喊口号
- **手法**：起点（为什么开始）→ 关键选择（放弃了什么、坚持了什么）→ 现在（具体证据）→ 主张；每一步有事实支撑
- **适用**：品牌稿、新闻通稿的背景段、官网“关于我们”、里程碑传播
- **边界**：只讲有据可查的经历，不虚构创始故事；“初心”“匠心”这类词用事实替代
