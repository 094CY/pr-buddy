## 一、转化策略（软转化，不硬卖）

### 核心原则

内容的第一目的是**让受众觉得“这篇有用、有意思”**，第二目的才是转化。受众感到被尊重时，转化自然发生。

### 转化三层

1. **认知层**：用痛点、变化、反常识洞察打开认知缺口
2. **认同层**：用案例、数据、原理、过程细节建立信任，让受众觉得“这家懂行、靠谱”
3. **行动层**：让受众主动想了解更多，或直接知道下一步去哪

### CTA 按主体与类型给

各主体的常见行动见 `enterprise-profiles.md`，这里只示意软写法：

| 主体 | 软写法（示意） |
|------|---------------|
| 传统制造与 B2B | “需要检测报告和样品的，可以联系我们的销售同事。” |
| 互联网与软件 | “如果你的团队也被这件事卡着，免费版就能先跑一遍。” |
| AI 与科技 | “文档里有完整的接入方式和适用条件，可以先评估再决定。” |
| 零售与消费品 | “这款在官方店铺和线下门店都有，规格看详情页。” |
| 门店与本地生活 | “店在XX路XX号，早六点到晚九点，周一休息。” |
| 工作室与小微品牌 | “更多作品在主页，档期可以私信问。” |
| 专业服务机构 | “遇到类似情况，可以带上材料来聊一次。” |

- **软硬与类型匹配**：深度文章、知识科普、案例故事用软 CTA 或不放 CTA；新闻通稿给联系方式；上新与促销文案、种草笔记、本地生活内容的行动路径要直接写清，这是受众需要的信息，不算硬广。
- **不说**：“立即抢购！手慢无！”（除非真的限量且写清数量）；“错过再等一年”（除非属实）。
- **结尾自然收束**：让受众带着一个新认知或一个清楚的下一步离开，而不是带着被推销的感觉离开。

## 二、结尾收束原则

结尾是最容易翻车的位置：前面铺了很好的洞察，结尾一旦变成卖点堆砌，读者立刻觉得被骗进了一篇软广。

**核心原则：结尾的叙事视角与开头一致。**

- 开头从行业问题切入 → 结尾回到行业方法层面收束
- 开头从变化趋势切入 → 结尾给出趋势判断
- 开头从客户或顾客困境切入 → 结尾提炼可复用的解题思路
- 开头从一个人或一个细节切入 → 结尾回到这个人或细节，让它多一层意义

**收尾认知不回落**：

- 检查：对比开头和结尾，结尾的认知层级不低于开头；文章“没走远”就再拔一层
- 拔高路径：“这件事怎么样” → “这件事意味着什么” → “这类事情的底层规律是什么”
- 不回落：结尾不突然从洞察回落到卖点介绍、从方法回落到操作指南

信息型内容（促销文案、产品手册、声明、种草笔记）不追求拔高，结尾落在受众需要的实用信息上。

**手法**：

1. **场景类比扩展**：把案例做法抽象为同类问题的解法
2. **方法复盘**：总结“为什么这个做法能跑通”
3. **反证说服**：“最难的场景都跑通了，更简单的场景没理由走不通”
4. **留白收束**：一个有力的判断或普适性洞察
5. **细节回环**：回到开头的人或物件

**❌ 反例（像产品文档）**：
> 它的使用门槛不高，标准版即可满足大部分需求，详细参数和接入方式可以查看产品文档。

**✅ 正例（洞察收束）**：
> 说到底，这家工厂解决的不是一个行业的专属问题，而是所有“订单多、批量小”的生意都绕不开的排产难题。答案不复杂：找到最痛的那个环节，用成熟的办法先跑起来，用数据说话。

**✅ 正例（细节回环，门店）**：
> 十二年过去，老板五点去菜场的习惯没变，变的是排队的人从街坊多了些拖着行李箱的外地人。

（示例中的事实须来自真实素材。）

## 三、合作关系植入

当主体与客户、伙伴存在合作关系（采购、联合开发、渠道、联名、共建）时，这是让内容更真实的叙事资产。合作信息回答的是：**为什么是这家？为什么能做成？**

### 写稿前必查

1. 合作类型与时间
2. 合作范围
3. 本次内容在合作中的定位
4. 双方表态（有公开信息才写，不虚构）
5. 是否可公开提及

### 三种线型

| 线型 | 适合 | 做法 |
|------|------|------|
| **暗线型** | 案例故事、深度文章 | 不单独开章节：开头自然过渡到合作背景；方案部分说明是合作中选定的切入点；结尾在“为什么能跑通”里带入合作方式 |
| **明线型** | 品牌稿、新闻通稿、活动稿 | 合作作为核心信息点直接展开 |
| **嵌套型** | 产品软文、实操教程、种草笔记 | 在“为什么选这个”的决策过程中自然提及；联名和商业合作按渠道规则标明 |

### 禁区

1. 不虚构合作，不把普通采购写成“战略合作”
2. 案例文章不写成新闻通稿（不报签约人、不列条款）
3. 合作背景不喧宾夺主
4. 没有特殊合作关系的不硬造

## 四、标题

**所有标题**：不用“国家级”“最高级”“最佳”自我评价；数字、排名有来源；促销标题的利益点与规则一致。

### 钩子矩阵（公众号、种草、本地生活、短视频通用；示例均为示意）

| 钩子 | 句式 | 示例 | 适用 |
|------|------|------|------|
| 痛点直击 | [你的XX为什么总是YY]？ | “你的客服为什么总在答非所问？” | 产品软文、案例 |
| 反常识 | [大家以为的XX，其实ZZ] | “小店做不起来，很少是因为味道” | 深度文章、知识科普 |
| 数字冲击 | [从A到B]，[主体]做对了什么 | “盘点从三天缩到一个下午，这家仓库做对了什么” | 案例故事 |
| 变化预判 | [领域]的[重点]已经变了 | “这个行业比拼的重点已经变了” | 深度文章 |
| 悬念设置 | [主体]这次没[做A]，做了一件更重要的事 | “这次没发新品，但做了一件更重要的事” | 品牌稿、活动稿 |
| 对比张力 | 当[多数人在做A]时，真正的难题在[B] | “大家都在比价格的时候，真正的难题在交期” | 专业解读、深度文章 |
| 场景代入 | 想象一下，[可代入的场景] | “想象一下，十个人同时跟你说话” | 知识科普 |
| 人物细节 | [一个人]，[一个反复做的动作]，[多久] | “凌晨四点的那锅骨汤，熬了十二年” | 品牌稿、门店内容 |
| 结果先行 | [具体结果]，[关键原因] | “装热汤放一下午，打开还是那个味” | 种草笔记、上新文案 |
| 地点锚定 | [街区/地标]附近的[品类]，[具体亮点] | “XX路尽头那家面馆，早上六点就排队” | 本地生活、探店 |
| 清单 | [人群]的[场景]，这[N]样[值得/够用] | “租房党的小厨房，这四样够用” | 种草笔记 |
| 比喻典故 | [对象]有了[意象] | “给仓库装上一双不会眨的眼睛” | 实操教程、知识科普 |

### 媒体发布

1. [主体][发布/升级/开业][对象]，[面向XX][实现YY]
2. [主体]在[活动/场景]中[动作]，[推动][价值]
3. [主体]助力[客户/行业][完成XX]，[结果]

### 专业社区

1. **实战记录**：[对象]上手实战：从[起点]到[终点]的完整记录
2. **踩坑分享**：[做某事]的第一周，我踩了这几个坑
3. **手把手**：手把手教你用[对象]实现[目标]
4. **效果对比**：把[指标]从[A]提升到[B]，我是怎么做的
5. **选型指南**：[场景]下怎么选[品类]：我们为什么选了[方案]
