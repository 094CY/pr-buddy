# 合规要点（写作自查，不构成法律意见）

> 写进论证卡「合规边界」之前对照本文件。法规会修订，涉及敏感类目时以现行条文为准；敏感类目的发布终稿提醒用户走法务或平台审核。条款序号为写作时核对的版本，仅供定位。

## 一、通用规则（所有类目）

| 要点 | 怎么写 | 依据 |
|------|-------|------|
| 内容真实 | 不虚构产品、服务、效果、销量、评价、获奖、合作；引用数据、统计、调查结果要真实准确并能说出出处，有适用范围和有效期的写明 | 《广告法》第十一条、第二十八条；《反不正当竞争法》第九条 |
| 绝对化用语 | “国家级”“最高级”“最佳”不用于自我评价；“唯一”“第一”“首家”“领先”“100%”须有可查证依据并说清范围，否则改为事实描述 | 《广告法》第九条（三） |
| 不贬低同行 | 不点名或影射贬低其他经营者的商品或服务；对比只用可查证事实 | 《广告法》第十三条；《反不正当竞争法》第十二条 |
| 专利与许可 | 提专利要写专利号和种类，不用申请中的专利冒充；许可、认证与实际内容一致 | 《广告法》第十一条、第十二条 |
| 赠送与免费 | 写清赠送的品种、规格、数量、期限和方式；“免费”有条件的写明条件 | 《广告法》第八条 |
| 可识别性 | 广告和商业合作内容要能被识别为广告；种草、测评、探店内容涉及商业合作的，按平台要求标注 | 《广告法》第十四条；《互联网广告管理办法》第九条 |
| 他人名义与代言 | 使用他人名义、形象须事先书面同意；代言人不得推荐未使用过的商品、未接受过的服务；不满十周岁的未成年人不得作代言人 | 《广告法》第三十三条、第三十八条 |
| 用户评价 | 不编造、不组织虚假评价；不以返现、好处诱导好评后当作真实口碑宣传 | 《反不正当竞争法》第九条 |
| 主动推送 | 短信、私信等主动发送广告要对方同意，并提供拒收方式 | 《广告法》第四十三条 |

## 二、价格与促销

| 要点 | 怎么写 | 依据 |
|------|-------|------|
| 被比较价格（划线价、原价） | 必须真实准确；没有标明含义的，不得高于本次促销前七日内的最低成交价；用厂商建议零售价比较的要明示 | 《明码标价和禁止价格欺诈规定》第十六条 |
| 先涨后降 | 不先提价再打折；不用无依据或无从比较的价格当比较基准 | 同上第十七条 |
| 赠品 | 标明赠品品名和数量；标价值的，按同一场所当前售价标 | 同上第十八条 |
| 规则清楚 | 不把不利条件（门槛、限量、限时、限品类）写得含糊或用小字弱化；“限时”“限量”须真实 | 同上第十九条 |
| 网络页面一致 | 首页、列表页的价格不得低于详情页实际价格；促销规则与实际执行一致 | 同上第二十条 |

**写作提示**：促销文案里的活动期限、适用门店、使用规则是合规信息，必须写清，不属于“人造时间标记”。

## 三、敏感类目

| 类目 | 不能写什么 | 依据 |
|------|-----------|------|
| 医疗、药品、医疗器械 | 广告须经审查；不写功效断言或保证，不说治愈率、有效率，不与其他产品比较，不用患者、专家、医生形象作证明；非医疗类内容不得变相宣传医疗用途 | 《广告法》第十六条、第十七条、第十九条、第四十六条 |
| 保健食品 | 不写疾病预防、治疗功能；不写保证安全或无副作用；须写“本品不能代替药物”；不与药品、其他保健食品比较 | 《广告法》第十八条 |
| 普通食品 | 不写疾病预防、治疗功能；不暗示保健功能；不虚构产地、工艺 | 《食品安全法》第七十三条；《广告法》第十七条 |
| 化妆品 | 不明示或暗示医疗作用（如“消炎”“治疗痘痘”“药妆”）；功效宣称须有科学依据；特殊化妆品按注册内容宣称 | 《化妆品监督管理条例》第二十二条、第三十七条、第四十三条 |
| 教育培训 | 不承诺升学、通过考试、获得证书或培训效果；不用考生、受益者或机构、专家名义作推荐证明 | 《广告法》第二十四条 |
| 金融与招商 | 不承诺收益、不暗示保本无风险（国家另有规定的除外）；须合理提示风险；不用专家、受益者名义作推荐证明 | 《广告法》第二十五条 |
| 房地产 | 不承诺升值或投资回报；面积写建筑面积或套内面积；不以项目到达某地点的时间表示距离 | 《广告法》第二十六条 |
| 酒类 | 不诱导、怂恿饮酒，不出现饮酒动作；不表示可以消除紧张焦虑、增加体力 | 《广告法》第二十三条 |
| 面向未成年人 | 不在中小学校、幼儿园内开展广告活动；针对未成年人的媒介不发布医疗、药品、保健食品、医疗器械、化妆品、酒类、美容广告和不利于身心健康的网络游戏广告；针对十四周岁以下的不写劝诱其要求家长购买的内容 | 《广告法》第三十九条、第四十条 |

## 四、责任与表述安全

- 涉及审核、诊断、风控、安全、检测的场景，写“工具辅助 + 人工决策”，不写暗示责任转移的措辞（“交给系统就不用管了”“AI 全权负责”）。
- 涉及监管与合规的内容，用“合规要求”“监管要求”描述，不点名具体监管机构、不描述具体处罚后果，除非引用公开文件原文且对本文必要。
- 不用政治化表述或可能引发误读的措辞，不以冲突叙事制造行业、群体或地域对立。
- 涉及个人信息的（顾客照片、聊天截图、手机号），只用已获授权且必要的部分，其余打码或删除。

## 五、论证卡「合规边界」怎么写

先判类目，再列本文据此不写的具体内容。示意：

- 普通类目：`普通类目，按通用规则；无价格比较和赠品`
- 门店团购：`普通餐饮；团购价只与门店现行售价比较，写明套餐内容、使用时段和有效期`
- 普通食品：`普通食品；不写任何调理、改善身体机能的说法，只写口味、原料和吃法`
- 培训课程：`教育培训；不写通过率、提分、包过，只写课程内容、师资资质和上课方式`
