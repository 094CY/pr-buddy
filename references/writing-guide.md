# 通用写作规则（Step 5）

> 所有类型通用。各类型自己的写法在 `types/` 对应文件里；事实准确、品牌安全、合规是底线，结构为内容服务。

## A. 内容与论证

1. **先给结论，再给证明**：尽早让读者知道“这篇在讲什么、跟我有什么关系”，具体在哪一句亮出来按渠道和节奏定。
2. **卖点翻译为价值**：不只说“304 不锈钢内胆”，要说“装热汤放一下午也没有怪味”；不只说“支持多人协同编辑”，要说“改方案不用再在群里传第七版文件”。
3. **场景自己构建，不照搬资料**：资料只说“有什么”，你要补“谁在什么情况下被什么问题卡住”：具体角色 + 具象物件 + 痛感动作。删掉场景后读着像参数表或价目表，说明场景没写到位。
4. **每段有信息增量**：删掉不影响理解的段落就删。
5. **因果链完整**：事件和趋势不凭空出现，交代导火索和关键演进阶段。
6. **核心信号可记忆**：全文有一句读者能记住并转述的核心信号；读完说不出来，说明立意淹没在细节里。
7. **读者已知的一句带过**：受众早就知道的品类常识、热门概念不从头科普；篇幅失控的首要原因是过度铺垫。
8. **首尾视角一致**：开头视角决定收尾视角，收尾认知层级不低于开头（手法见 `marketing-strategy.md`）；信息型内容收在受众需要的实用信息上。

## B. 事实、品牌安全

1. **数字有依据**：数字、排名、销量、评分、客户名称、效果数据都要有来源，没有的按 `brand-fact-sheet.md` 处理。
2. **命名一致**：主体名、门店名、产品名、版本名、客户名全文写法一致；有正式商业命名的用正式名称。
3. **不贬低同行**：不点名或影射同行不行，不用“别家都是……只有我们……”的句式，用事实和案例说话。
4. **敏感类比**：不用政治、宗教、灾难事件做类比。
5. **合规**：绝对化用语、功效、承诺、价格、责任主体等一律按 `compliance-notes.md`。
6. **零时间标记**：标题不带日期括号；正文不写“截至目前”“截至 X 年 X 月”“更新时间”等时间戳式表述，不逐句标“（据XX，年-月）”。叙事中的事件时间（通稿导语里的发布日期、“2019 年开出第一家店”）是事实内容，可以写；促销有效期、营业时间是合规与实用信息，必须写清。

## C. 表达与格式

1. **小标题有信息量和画面感**：不用“一、概述”式空壳，也不用“从A到B的C”式学术标题。好的有场景（“凌晨四点的那锅骨汤”），差的只有概念。
2. **段落宜短但不切碎**：手机端短段落好读，论点需要完整展开时保持完整。
3. **专业内容三明治**：业务或生活意义 → 原理或工艺 → 收益。
4. **篇幅**：不设硬性限制，唯一标准是没有一段在凑字数。
5. **字数**：头部字数只写 `wordcount.py` 给出的数字（1 汉字、1 英文词、1 数字串各算 1 字，中文标点计入），不凭印象估。
6. **去 AI 痕迹**：按 `anti-ai-traces.md`。
