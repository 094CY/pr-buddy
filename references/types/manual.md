# 产品手册与服务说明

**使命**：清晰、准确、结构化，语言精确，不用营销话术。
**风格**：主用专业纵深；辅以实战复现；慎用观点锐度、通俗趣味。

## 采集

1. 名称、版本或型号、一句话定位
2. 功能或服务项目清单（每项：名称、说明、场景）
3. 参数、规格或价目，包含与不包含的内容
4. 使用或服务流程
5. 售后、退改、保修规则
6. 常见问题
7. 联系方式

## 官网与文档版

1. 概述：一句话定位 + 核心能力或服务范围
2. 功能或服务项目：结构化表格，每项附场景说明
3. 参数、规格或价目：限制条件、包含与不包含的内容
4. 使用或服务流程：分步骤
5. 推荐用法或注意事项
6. FAQ：预判常见问题（含售后、退改、保修）
7. 联系方式

## 按主体调整

软件写接入与配置，代码示例可直接复制运行；制造与消费品写规格、安装、保养；门店与工作室写服务项目、价目、预约与退改规则；专业服务写服务范围、流程、收费方式与边界。
