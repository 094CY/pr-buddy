# 专业解读

**使命**：面向懂行的人和决策者，专业且实用，不需要过度通俗化。
**风格**：主用专业纵深；辅以产业落地、多信源与数据锚定（含概念具象化）；慎用通俗趣味（会失准）。

## 采集

1. 主题与版本、型号、标准编号或法规名称
2. 核心创新或关键结论
3. 关键指标与测试条件
4. 与基线或通行做法的对比（附来源）
5. 落地条件：部署、生产、执行要求
6. 已知限制与适用边界

## 公众号版

**标题**：明确主题 + 关键创新点或关键结论
**正文**：

1. 问题背景：要解决的核心挑战
2. 方案或原理拆解：架构、工艺、方法、条款逐层讲清
3. 指标与对比：与基线或通行做法对比，指标、标准编号、条款精确，出处可查
4. 落地细节：部署、生产、执行中的条件和限制
5. 应用效果
6. 获取方式与资源
7. CTA：面向专业受众的行动引导

## 官网与文档版

去掉叙事性开头，直接进入主题；增加参数表、示例；用标准文档结构。

## 专业社区版（技术社区、行业论坛、问答平台）

可用第一人称或团队视角；增加选型决策过程；代码或步骤可复现；增加踩坑与调优经验；语气平等。

## 按主体调整

AI 与软件讲架构和接口；制造讲工艺和标准；消费品讲成分与原理；专业服务讲法规、准则和实务判断。
