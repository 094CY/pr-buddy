# 声明与回应

**使命**：事实准确、态度诚恳、口径稳妥。
**风格**：主用专业纵深（事实）、论证推进（把道理讲透时）；慎用观点锐度、通俗趣味。

## 采集

1. 事件经过：已核实的事实、仍在核实的部分
2. 受影响对象与范围
3. 主体立场（是否致歉、为什么）
4. 已采取和将采取的措施、时间节点
5. 联系与处理渠道
6. 是否经过法务审阅

## 通用结构（官方账号、媒体、社群）

```
关于[事件]的说明

[事实：发生了什么，已核实的部分]
[态度：对受影响的人表达立场]
[措施：已经做了什么、接下来做什么、时间节点]
[渠道：受影响者如何联系、如何处理]
[主体名称]
```

## 写法要点

- **只写已核实的**：未核实的写“正在核实，结果会第一时间公布”，不猜测原因、不扩大或缩小范围。
- **致歉要具体**：说清为什么致歉、对谁致歉，不写“给大家带来不便深表歉意”这种空话。
- **不辩解、不甩锅**：不把责任推给员工个人、供应商或顾客；不攻击投诉者或媒体。
- **措施可兑现**：只承诺做得到的，写时间节点。
- **提醒法务**：涉及法律责任、伤害、赔偿的，交付时提醒用户先让法务审阅。
