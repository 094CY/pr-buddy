# 新闻通稿

**使命**：信息准确、口径统一、媒体可直接转载。
**风格**：主用专业纵深；辅以商业洞察、品牌叙事；需要行业数据时加多信源与数据锚定；慎用观点锐度、体验种草。

## 采集

1. 主体一句话定位
2. 本次动作：发布、升级、开业、融资、签约、获奖、里程碑
3. 面向的客户、行业或人群
4. 核心问题与价值主张
5. 核心亮点（每点含：是什么、依据、受众收益）
6. 关键数据或可观察结果（附来源）
7. 获取方式：购买、试用、到店、预约
8. 可信支撑：资质、检测、合作方、过往记录
9. 负责人或合作方的真实引语（如有）
10. 合作关系信息（如适用）：形式、时间、范围、是否可公开、有无落地佐证

## 媒体发布版

**标题**：`[主体] + 动作词 + 产品/服务/事件 + 价值结果`
**导语**：`[日期]，[主体]在[地点][动作][对象]。[对象]面向[受众]，聚焦解决[问题]。` 交代 5W1H，读完就能独立成一条消息。
**正文**：

1. 关键信息：发布范围、适用对象、上线或开业状态、价格或获取方式（如适用）
2. 核心亮点：能力或特色 → 依据 → 受众收益
3. 场景价值：按行业、人群或使用场景展开
4. 可信支撑：资质、检测、合作方、过往记录（有来源才写）
5. 各方表态（如有）：负责人或合作方的真实引语
6. 主体简介与联系方式

**语气**：官方、克制、事实密度高，不做情绪铺垫，形容词换成事实。

## 公众号版

**标题**：突出痛点、结果或变化，再带出主体动作
**正文**：开头钩子（受众痛点或场景矛盾）→ 为什么是现在 → 这次做了什么 → 能带来什么变化（几个短小亮点或场景片段）→ 适合谁 → 怎么获取 → CTA

## 按主体调整

B2B 与软件强调能力与接入；消费品强调产品与购买渠道；门店（开业、周年、新店）的关键信息里必须有地址、营业时间、招牌出品和开业活动规则；工作室与专业服务强调服务范围和预约方式。

## 高发失误

把“即将上线”写成“已上线”；奖项、排名简化成“第一”；引语编造。
