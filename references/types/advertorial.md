# 产品软文

**使命**：有价值感，转化自然，不像硬广。
**风格**：主用商业洞察、产业落地；辅以通俗趣味、体验种草；替受众说痛点时加论证推进。

## 采集

1. 目标受众的具体痛点
2. 痛点为什么越来越紧迫
3. 产品或服务如何解决
4. 解决后的效果（数据或可观察变化，附来源）
5. CTA 方向

## 公众号版

**标题**：从受众痛点切入，一般不提产品名
**正文**：

1. 痛点场景
2. 问题放大：为什么越来越紧迫
3. 解题思路：先给方向，不急着提产品
4. 方案引入：产品或服务作为解法自然带出
5. 效果验证：数据、案例、对比
6. 场景延展
7. 软引导

## 写法要点

- 多数篇幅讲问题和价值，少部分讲方案。
- 效果数据只用有来源的；没有就写可观察的变化（“不用再……”）。
