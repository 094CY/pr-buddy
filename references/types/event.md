# 活动稿

**使命**：传达关键信息，不写流水账。
**风格**：主用商业洞察（信息密度）；辅以观点锐度（提炼）。

## 采集

1. 名称、时间、地点、主办方、费用
2. 主题与目标受众
3. 核心发布、议题、福利或体验
4. 嘉宾、合作方
5. 现场亮点（回顾稿）
6. 嘉宾原话（有出处）
7. 参与或后续方式

## 预告稿

钩子（为什么值得来）→ 活动信息（时间、地点、主题、面向谁、费用、名额）→ 核心看点（议题、嘉宾、发布、福利）→ 参与方式（报名、到店、预约）→ CTA

## 回顾稿

开头（释放了什么信号或留下了什么）→ 核心内容（提炼少数最有价值的信息点）→ 亮点时刻（嘉宾原话、重要演示、现场细节）→ 意义（对受众和行业意味着什么）→ 后续（回看、资料、下一场）

## 媒体发布版

导语交代基本信息；正文聚焦少数核心发布或观点，不写全议程。

## 按主体调整

展会与峰会突出发布与观点；门店活动（周年庆、市集、品鉴会）突出现场体验和参与规则，写清时间、地点、福利数量；工作室活动（展览、体验课）突出作品与名额。
