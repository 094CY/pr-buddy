# 种草笔记

**使命**：像真人分享，有体验细节，信息可信。
**风格**：主用体验种草；辅以通俗趣味、人情烟火；慎用专业纵深（太硬）、品牌叙事。

## 采集

1. 真实体验素材：谁用的、在什么场景、具体感受（用户提供）
2. 产品或门店基本信息：名称、规格、价格、购买渠道或地址、营业时间
3. 亮点与不足
4. 适合人群与不适合人群
5. 是否为商业合作（决定是否标注）
6. 目标平台与话题方向

## 图文种草社区版（主力渠道）

**标题**：具体场景或具体结果 + 一个让人想点的细节；不堆感叹号和 emoji
**首图建议**（文字描述，写在交付说明里）：场景图或前后对比
**正文**：

1. 一句话说清“我为什么需要它”：场景或痛点
2. 体验细节：看到、摸到、尝到、用到的具体感受
3. 实用信息：规格、价格、在哪买或店在哪、怎么用；门店加人均、排队情况、营业时间
4. 适合谁、不适合谁：哪里一般也要说
5. 小提示：使用技巧、避坑点
6. 话题标签：与内容相关的少量标签

## 写法要点

- **真实第一**：第一人称体验只写真实发生的。用户没给体验素材时，改写成“攻略型”或“清单型”（第三方视角介绍信息与选购判断），不编“我用了一个月”。
- **细节具体**：“杯盖拧三圈才到底”“汤底撇过油，喝完嘴唇不粘”，不写“质感绝了”。
- **利弊都说**：只夸不说缺点的笔记可信度低。
- **商业合作**：按平台规则标明。
- **类目边界**：不写功效承诺，具体对照 `compliance-notes.md`。

## 按主体调整

门店写探店路线（位置、环境、点了什么、人均、排队情况、营业时间）；消费品写使用场景和对比；工作室写体验流程和成片或成品。
