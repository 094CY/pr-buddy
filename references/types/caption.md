# 社群/朋友圈配文

**使命**：独立的微内容，不是文章的缩写：引发好奇 → 传达价值 → 触发点击或到店。默认不输出，用户要才写。
**风格**：主用观点锐度（钩子）、通俗趣味；辅以人情烟火；慎用专业纵深。

## 采集

1. 原文标题和核心信息（或直接附文章），或要通知的事项
2. 转发场景：朋友圈 / 微信群 / 客户群 / 会员群 / 内部群
3. 转发人角色：官方号 / 老板或主理人 / 销售 / 员工
4. 是否需要多条不同方向

## 输出格式（不用常规稿件头部，lint 用 `--short --no-card`）

```
方向：[配文方向名称]
适用：[转发场景]
---
[配文正文]
```

用户要配文时给几条不同方向的备选。

## 配文方向（示例均为示意）

| 方向 | 写法 | 适用 | 示例 |
|------|------|------|------|
| 悬念钩子型 | 抛一个未完成的判断或问题 | 深度文章、知识科普 | “多数小店做不起来，原因不在味道。” |
| 核心结论型 | 把最有冲击力的结论直接亮出来 | 品牌稿、案例故事、深度文章 | “仓库少走一半冤枉路，靠的不是加人。” |
| 场景共鸣型 | 描述目标受众会心一击的场景 | 产品软文、案例故事、教程 | “每次月底对账对到半夜的人，看看这篇。” |
| 数据冲击型 | 用有来源的数字制造落差 | 案例故事、专业解读 | “三天的盘点，现在一个下午做完。” |
| 店主口吻型 | 老板或主理人第一人称，像在群里说话 | 门店、工作室的上新、活动、日常 | “秋天第一锅羊肉汤明天开卖，骨头熬了一整夜。前五十碗送一份烤饼，卖完就没了。” |
| 行业观察型 | 站在行业视角评论一句 | 深度文章、品牌稿、活动稿 | “这一行比的早就不是价格了。” |

示例中的数量、赠品须与真实活动规则一致。

## 底线

一般一到三句话；有完整信息价值，不是“好文推荐”这种空话；emoji 少用；不用“重磅”“必读”“建议收藏”等过度营销词；促销配文同样写清规则；论证卡豁免，但类目红线照样不能踩。
