# 知识科普

**使命**：有趣、易懂、能传播，不牺牲准确性。
**风格**：主用通俗趣味、观点锐度；辅以专业纵深（保准确）、产业落地（落地感）；慎用品牌叙事（会变软广）。

## 采集

1. 要解释的知识点
2. 读者预设水平：完全外行 / 有基本认知 / 半专业
3. 想用的场景或比喻（可选）
4. 实际应用或选购判断方法
5. 是否关联主体（仅科普则可不关联）

## 公众号 / 图文种草社区版

**标题**：生活场景或比喻 + 知识点，引发好奇
**开头**：一个受众熟悉的日常场景或常见误区
**正文**：

1. 场景或误区引入
2. 用类比翻译专业知识
3. 类比之后补一句准确定义
4. 实际应用或选购判断方法
5. 这件事跟你有什么关系（收尾回到这里）
6. 轻引导：主体作为“一个选择”自然出现，或不出现

## 写法要点

- 有趣但不低幼，通俗但不失准；允许适度幽默，不用网络烂梗。
- 品牌露出克制；一旦变成通篇夸自家产品，就改按产品软文写。
- 选购指南类：给判断方法和标准，不给“只买某某”的结论。
