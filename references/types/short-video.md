# 短视频脚本

**使命**：开头抓住注意力，节奏紧凑。
**风格**：主用通俗趣味、观点锐度（钩子）；辅以体验种草、人情烟火；慎用专业纵深（太长太深）。

## 采集

1. 视频主题（一句话）
2. 目标平台
3. 目标时长（建议范围，不强制）
4. 出镜形式：口播 / 画面 + 旁白 / 探店跟拍 / 产品演示 / 录屏
5. 核心信息点（宁少勿多）
6. CTA 方向

## 输出格式（不用常规稿件头部，lint 用 `--short`；论证卡照写）

```
视频主题：
目标时长：
出镜形式：

| 段落 | 画面 | 台词或字幕 |
|------|------|-----------|
| 钩子 | | |
| 问题 | | |
| 展示 | | |
| 佐证 | | |
| 行动 | | |
```

1. **钩子**：提问、冲突、反差或结果先行
2. **问题**：简短的痛点场景
3. **展示**：产品、服务、出品、过程怎么解决问题
4. **佐证**：有来源的数据、真实顾客反馈或过程画面
5. **行动**：明确下一步（店在哪、怎么买、怎么约）

各段时长按总时长和内容分配，不固定秒数。

## 写法要点

- 口语化，像跟朋友安利一个好东西；门店与工作室可写成老板或主理人口吻。
- 画面写可拍摄的具体动作，与台词对应。
- 口播里的价格、优惠同样要写清规则。

## 标题思路

`[数字] + [冲击性事实]`；`[提问] + [反转暗示]`；`[场景] + [意想不到的结果]`
