# 品牌稿

**使命**：事实清晰、价值突出、克制但有力。
**风格**：主用品牌叙事、商业洞察；辅以人情烟火、论证推进；慎用过度口语的通俗趣味。

## 采集

1. 主体一句话定位
2. 本次动作或里程碑；为什么开始、关键选择（放弃了什么、坚持了什么）
3. 面向的客户、行业或人群
4. 核心问题与价值主张
5. 核心亮点（每点含：是什么、依据、受众收益）
6. 关键数据或可观察结果（附来源）
7. 可信支撑：资质、合作方、具名客户或真实顾客（可公开）
8. 负责人或合作方的真实引语（如有）
9. 合作关系信息（如适用）：形式、时间、范围、是否可公开、有无落地佐证

## 媒体发布版

**标题**：`[主体] + 战略动作或里程碑 + 价值主张`
**开头**：从行业或受众的变化切入，快速落到主体的实际动作，不长篇铺垫
**正文**：

1. 背景变化与主体动作
2. 核心内容与价值主张
3. 差异化：只用可查证的事实
4. 应用或受益场景
5. 落地佐证（如有）：从合作或决策到落地的递进路径，用有来源的数据说话
6. 主体定位：只写已公开、已落地的方向
7. CTA 或联系方式

## 公众号版

**标题**：一个有张力的判断、变化或具体细节
**正文**：变化引子（一个具体的人或物件也可以）→ 主体的回应（做了什么选择、为什么）→ 核心看点 → 对受众意味着什么（可用一个“选择 → 落地 → 结果”的真实片段）→ 行业或生活视角的观察 → 收束：品牌主张回扣，门店附到店信息

## 按主体调整

门店、工作室以人物和细节为主线（谁、为什么开始、坚持了什么）；制造与 B2B 以能力积累和客户信任为主线；软件与 AI 以用户问题和产品选择为主线；专业服务以专业判断和服务原则为主线。

## 写法要点

- 亮点用“是什么 → 依据 → 受众收益”三层展开；能力展示按受众能感知的价值筛选，不做手册式全量罗列。
- **案例支撑**：需要具名客户、真实顾客或合作方做可信度支撑（前提是可公开）；全文找不到一个可验证的支撑时向用户要，拿不到标 `[待确认]`。
- **只写已落地的事**：不展望未落地的路线图、未开的店、未上的品。
- **不喊口号**：“匠心”“初心”“品质”这类词，用一个具体事实替代（师傅做了多少年、为什么换了供应商、哪道工序不省）。
- 结尾一段收束即可，不在尾部再开新章节新论点。
- 涉及政策或行业热点背景时，读 `argumentation-guide.md`「政策与热点锚定」。
