# 上新与促销文案

**使命**：卖点（为什么值得买）、利益点（这次划算在哪）、规则（怎么享受、有什么限制）三件事讲清楚。
**风格**：主用体验种草、通俗趣味；辅以专业纵深（卖点准确）；慎用论证推进。

## 采集

1. 产品或套餐名称、规格、包含内容
2. 核心卖点及依据
3. 价格：现价、被比较价格（含义与依据）、优惠方式
4. 赠品：品名、数量
5. 规则：活动期限、适用门店或渠道、使用时段、门槛、限量
6. 购买或到店路径
7. 目标渠道（本地生活平台、种草社区、社群、详情页、公众号）

## 通用结构（按渠道和篇幅取舍）

1. 钩子：新在哪里，或这次的利益点
2. 产品或套餐：名称、规格、核心卖点（“现烤”→“下午三点那炉出来时还烫手”）
3. 利益点：价格、优惠、赠品
4. 规则：写在显眼处，不用小字弱化门槛；能否叠加也写清
5. 行动路径：购买链接、店铺名、地址与营业时间、预约方式

价格、划线价、赠品、“限时”“限量”的写法对照 `compliance-notes.md` 第二节。

## 按渠道调整

- **本地生活平台**：信息直给、条目化，格式如下
- **社群**：一到三段，像店主在群里说话
- **详情页**：卖点与参数并列
- **公众号**：可加一段场景或故事

```
【新品/套餐名】[一句话利益点]

· 套餐内容：[菜品/项目与份量]
· 价格：[现价]（[被比较价格及其含义]）
· 赠品：[品名 × 数量]（如有）
· 有效期：[起止日期]；使用时段：[时段]
· 适用门店：[门店名与地址]
· 使用规则：[是否需预约、是否可叠加、限购]
```
