# 主体事实表（Step 1.6）

> 写作前按本表整理事实，缺什么就向用户要或标 `[待确认]`。本表是内部工作底稿，不进正文。

## 核查方法

1. **一手资料核查**：用户提供的资料优先；其次查官网、官方店铺页、产品说明、公开登记信息、主体的官方账号。
2. **逐项比对**：稿件里每一条事实都与一手资料比对。
3. **定位零篡改**：资料写“手作烘焙工作室”就写“手作烘焙工作室”，不擅自升级成“烘焙品牌”“连锁”；资料写“智能客服系统”就不改成“大模型平台”。
4. **无来源数据**：查到可靠来源 → 保留具体数字；查不到 → 改为定性描述；定性也无法确认 → 标 `[待确认]`；纯装饰性的数字 → 删除。
5. **评价与案例真实可授权**：必须来自用户提供的真实素材且可公开；没有就不写，不用“很多顾客说”去凑。
6. **来源心里有数**：关键事实要能说出来自哪里，不写进终稿；媒体投稿版按惯例在正文写明出处。

## 一、通用事实表（所有主体）

| 项 | 说明 | 核对要点 |
|----|------|---------|
| 主体全称与简称 | 公司、品牌、门店或工作室名称 | 与工商登记、平台登记、商标一致；全文写法统一 |
| 一句话定位 | 主体自己怎么描述自己 | 按原文，不擅自升级（“工作室”不写成“品牌集团”） |
| 本次主题 | 发布什么、上新什么、开业还是活动 | 时间、地点、对象具体 |
| 产品或服务 | 名称、规格、型号、服务项目 | 用正式名称；规格与说明书或详情页一致 |
| 价格与优惠 | 售价、活动价、套餐、赠品、条件 | 原价是否真实成交过；赠品品名数量；活动期限与适用范围 |
| 卖点与依据 | 每个卖点对应的事实依据 | 检测报告、认证证书、专利号、公开数据；没有依据的卖点改定性或删 |
| 资质与认证 | 许可证、认证、奖项 | 名称、颁发机构、有效期；奖项写全称，不简化成“行业第一” |
| 数据 | 销量、用户数、增长、效果 | 来源、口径、统计范围；无来源按上方“无来源数据”处理 |
| 联系与转化路径 | 地址、营业时间、购买渠道、预约方式、咨询入口 | 与平台信息一致 |
| 品牌口径 | 必须用的说法、不能说的话、主色 | 用户给的口径优先于本 Skill 默认规则（法定要求除外） |

## 二、按主体类型追加

| 主体类型 | 追加采集项 |
|----------|-----------|
| 传统制造与 B2B | 产能与交期、执行标准编号、检测报告、主要设备或工艺、服务区域、标杆客户（授权情况） |
| 互联网与软件 | 版本号与上线状态、定价方案、免费额度与限制、支持的平台与集成、数据安全与合规认证 |
| AI 与科技 | 技术名词的官方定义、能力边界与适用条件、评测来源与口径、是否已商用、数据处理方式 |
| 零售与消费品 | 成分或材质、执行标准、产地、保质期或保修、特殊类目的注册或备案信息、渠道与价格 |
| 门店与本地生活 | 平台登记店名、地址与交通、营业时间、招牌出品、套餐内容与使用规则、预约方式、老板或主理人信息 |
| 工作室与小微品牌 | 主理人背景、代表作品（授权）、服务流程、价目与包含内容、档期与交付周期 |
| 专业服务机构 | 执业资质、团队构成、服务范围与边界、典型案例（脱敏与授权）、行业宣传规范 |

## 三、案例、评价与人物授权

| 项 | 要求 |
|----|------|
| 客户名称 | 公开授权才写全称；未授权写“某连锁餐饮企业”之类的脱敏称呼，且不给出可反推身份的细节 |
| 客户或顾客原话 | 来自真实访谈、评价截图或书面反馈，可公开；不编造、不“润色”成没说过的话 |
| 效果数据 | 客户确认过的口径；写清统计范围，不把个例写成普遍效果 |
| 人物形象与姓名 | 使用他人名义、形象须事先取得同意；未成年人信息格外谨慎 |
| 合作关系 | 写真实的合作形式（采购、联合开发、渠道合作），不夸大为“战略合作” |

## 四、高发编造清单（写到这些先停一下）

百分比、销量、复购率、好评率、排名、耗时、服务人数、开业年限、“回头客占比”、“累计服务 XX 家企业”、“XX 万用户的选择”、“XX 年老店”、“行业领先”、“爆款”。

每一个都要能对上本表里的来源；对不上的，按上方“无来源数据”处理。
